Leave the rebuy stack empty to use the starting stack.

One level per line: sb,bb,ante,minutes or break,minutes.

A level line can carry the optional prefixes game= and fmt= (in any order). The format decides the columns: blind-nl is sb,bb,ante,minutes, blind-limit is sb,bb,big_bet,ante,minutes (an empty or - big bet is derived from the BB) and stud-limit is bring_in,complete,ante,minutes. Example: fmt=blind-limit 100,200,400,0,20 or game=Stud fmt=stud-limit 25,100,25,20.

Game mix: the games that rotate, one game every levels per game levels. Leave the games empty for a single game.
